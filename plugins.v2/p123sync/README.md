# 123云盘同步（p123sync）

本地目录**单向同步**到 123 云盘的 MoviePilot V2 插件：不经过 MP 的识别/整理链，
整棵目录树原样复制（未识别内容照样传），侧栏「123云盘同步」页面实时查看任务状态与
逐文件上传进度。

## 特性

- **免识别整树同步**：配置 `源目录 → 123云盘目标目录`，自动递归比对后只传差异
- **同名冲突策略**（每任务对可配）：
  - `大小一致时跳过`（默认：同名同大小直接跳过，不做MD5预校验；可开启「严格MD5校验」
    恢复逐文件比对，远端缺校验值时报告失败）
  - `覆盖`（先上传并核验临时文件，替换成功后旧文件进入 123 回收站）
  - `保留两者`（新文件自动加 ` (2)` 后缀）
- **MD5 缓存**：上传与严格校验用到的 MD5 按 `路径+大小+修改时间` 缓存在本地状态库，
  文件未变化时不再重读整个文件；重试失败文件也不再重复计算
- **并行严格校验**：开启严格校验时按 4 线程并行计算 MD5，页面显示「校验 i/N 当前文件」进度
- **云盘同名重复文件**：123 云盘允许同目录存在同名文件（API 上传、回收站恢复等产生）。
  遇到时不再中断整个同步：默认模式下任一副本与本地大小一致即视为已存在并跳过
  （严格校验按 MD5 匹配）；无法确认时仅该文件报失败并提示到云盘删除多余副本，其余文件照常同步
- **失败退避**：监控任务中同步失败的文件按指数退避自动重试；连续 5 次相同错误后暂停
  自动重试（文件内容变化后自动恢复，手动同步不受影响），避免不可恢复的失败反复重试刷屏
- **秒传 + 分片上传**：先按 MD5 尝试秒传，命中零流量；未命中按分片上传（失败自动重试并重取 URL）
- **可视化**：侧栏独立页面（Vue 联邦模块）——运行阶段徽标、总进度/速度/ETA、
  任务对子进度、逐文件百分比进度条、历史记录；仪表盘小组件速览
- **目录选择**：可逐级浏览容器内本地目录和 123 云盘已有文件夹，也可手动输入新路径
- **文件明细**：服务端分页；失败文件可单独重试或批量重试，其他结果保留
- **完整目录核对**：按云盘分页总数核验目录；遇到限流会退避重试，同名冲突会核对目标目录中的文件
- **同步方式**：每个任务可选择手动同步、目录监控或下载器监控；可选 Cron 仅用于手动任务
- **恢复**：文件状态、监控队列与替换步骤持久化；中断后重试会先核对云盘结果

## 使用

1. 安装插件（依赖 `p123client` 会自动 pip 安装）
2. 插件设置：填写 123 账号密码 → 「验证登录」→ 添加同步任务对，点击路径输入框展开树形目录并选择（源目录必须是 MP
   容器内可见的本地路径）→ 按需配置 cron
3. 侧栏打开「123云盘同步」，可运行全部任务或单个任务；在仪表板中可添加同步小组件
4. 同步中保存设置会进入待生效队列；任务及未解决的失败处理完成后自动应用，也可取消待生效设置
5. 更新插件后刷新 MoviePilot 页面；设置页应显示「基本设置」，添加任务后点击路径输入框即可展开目录树

## 说明

- 走 123 网页端接口（同 p123disk 插件），token 数超限自动重连；非官方开放平台，
  接口变更可能导致失效
- 上传流量经 MP 容器出口；远端目录按 100 条/页列举，请求限速并在被云盘限流时退避重试，大目录首轮比对较慢
- 默认忽略以 `.` 或 `~$` 开头的隐藏文件/目录、常见未完成下载后缀及系统垃圾文件；也可按任务配置排除扩展名
- 目录监控每 30 秒周期检查，首次启用也会发现已有文件；文件大小与修改时间须持续稳定（默认 120 秒）才自动同步。稳定时间是启发式，不能证明暂停下载的文件已完成
- 下载器监控要求 MoviePilot 能查询下载器任务和逐文件完成状态，并正确映射保存路径；只处理确认完成且被选中的文件。无法确认的文件保留等待，不按整个目录猜测上传
- 手动点击“同步”或“全部同步”会扫描所选任务的完整源目录；请确保文件已写入完成
- 同步状态与逐文件恢复信息保存在插件数据目录；中断后可查看失败文件并重试。历史摘要显示最近 20 次
- 恢复以文件为单位核对云盘；未完成文件可能需要重新上传，不承诺跨进程续传单个分片
- 失败的替换可能留下 `p123sync-stage-...` 临时文件和 `p123sync-backup-...` 旧文件；请先在插件中重试核对，不要手动删除这些文件
- 取消会在当前阻塞网络请求返回后生效；哈希计算和分片重试等待可及时响应取消
- 进度包括当前文件已确认的分片；传输量不包含秒传，也不能计入失败请求中未获确认的字节
- 本版本提供单文件 Release 安装包；支持 Release 的 MoviePilot 优先使用该包，失败时可回退文件列表
- 监控文件的观察记录和待处理状态保存在插件数据目录；同步失败按退避间隔自动重试，已有未解决失败会阻止新监控批次覆盖当前记录
- 自动触发（监控/定时/重试）的同步在失败集合与错误内容都没有变化时不重复推送通知；一次全部成功的同步会恢复提醒。手动同步始终推送
- 某个任务对在扫描或列举阶段失败（如源目录不可用、云盘同名目录）只影响该任务对，其他任务对继续同步
- 重试会重新扫描和比对所选失败文件，按当前任务的同名策略处理；任务配置变更后需重新运行任务
- 删除操作仅进 123 回收站，可从网页端找回

## 前端构建与发布

在 `frontend.v2/p123sync` 执行 `npm ci`、`npm test` 和 `npm run build`。
将构建后的联邦模块、辅助 JS 和 CSS 复制到 `get_render_mode()` 返回的版本目录，
并检查 `remoteEntry.js` 引用的文件都存在。更新版本时使用新的资源目录，避免旧入口被缓存。
从仓库根目录执行 `python .github/scripts/package_p123sync_release.py <输出路径>`，
将生成的 `p123sync_v<版本>.zip` 发布到对应 `P123Sync_v<版本>` Release。
