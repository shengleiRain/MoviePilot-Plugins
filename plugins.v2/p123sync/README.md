# 123云盘同步（p123sync）

本地目录**单向同步**到 123 云盘的 MoviePilot V2 插件：不经过 MP 的识别/整理链，
整棵目录树原样复制（未识别内容照样传），侧栏「123云盘同步」页面实时查看任务状态与
逐文件上传进度。

## 特性

- **免识别整树同步**：配置 `源目录 → 123云盘目标目录`，自动递归比对后只传差异
- **同名冲突策略**（每任务对可配）：
  - `相同大小跳过`（默认，幂等，可反复全量跑）
  - `覆盖`（旧文件进 123 回收站后传新版）
  - `保留两者`（新文件自动加 ` (2)` 后缀）
- **秒传 + 分片上传**：先按 MD5 尝试秒传，命中零流量；未命中按分片上传（失败自动重试并重取 URL）
- **可视化**：侧栏独立页面（Vue 联邦模块）——运行阶段徽标、总进度/速度/ETA、
  任务对子进度、逐文件百分比进度条、历史记录；仪表盘小组件速览
- **触发**：页面手动（全部/单个任务对/取消）+ 可选 cron 定时（注册进 MP 服务管理）
- 断点友好：取消/失败后重跑，已完成（相同大小）自动跳过

## 使用

1. 安装插件（依赖 `p123client` 会自动 pip 安装）
2. 插件设置：填写 123 账号密码 → 「验证登录」→ 添加同步任务对（源目录必须是 MP
   容器内可见的本地路径）→ 按需配置 cron
3. 侧栏打开「123云盘同步」→ 「全部同步」

## 说明

- 走 123 网页端接口（同 p123disk 插件），token 数超限自动重连；非官方开放平台，
  接口变更可能导致失效
- 上传流量经 MP 容器出口；远端目录列举按 100/页 + 1s 间隔限速，大目录首轮比对较慢
- 删除操作仅进 123 回收站，可从网页端找回
